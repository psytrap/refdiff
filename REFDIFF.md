# RefDiff: Architecture & Tool Design Specification
*Subtitled: The Ref-Differentiator*

A zero-loss diff-decoupling engine and visualization gadget for MediaWiki `Special:Diff` that eliminates "template camouflage" by separating prose edits from citation metadata changes.

* **Tool Name:** `RefDiff`
* **User Script / Gadget:** `refdiff.js` (for MediaWiki `Special:Diff`)
* **Conceptual Subtitle:** *Ref-Differentiator*
* **Repository Role:** Reviewer companion and diff-inspection gadget for citation decoupling and the Section-Scoped References (`<references hidden>`) ecosystem.

> [!NOTE]
> For the comprehensive engineering specification, state machine diagrams, DOM Memento pattern, and subsystem class definitions, see [**ARCHITECTURE.md**](ARCHITECTURE.md).

---

## 1. Naming & Concept Rationale

**`RefDiff`** (conceptually described as the **Ref-Differentiator**) carries a deliberate triple meaning:
1. **Differentiating Prose from Citations:** It functionally decouples two fundamentally orthogonal layers—factual assertions (prose) and evidentiary support (citations).
2. **Diffing References in Isolation:** It calculates dedicated, granular diffs for bibliographic metadata (e.g. highlighting that only `|pages=45` changed to `|pages=52`) without dragging the surrounding paragraph into the diff hunk.
3. **The Spiritual Successor to *References Segregator*:** While PleaseStand's 2011 [**References Segregator**](https://en.wikipedia.org/wiki/User:PleaseStand/References_segregator) ([`User:PleaseStand/segregate-refs.js`](https://en.wikipedia.org/wiki/User:PleaseStand/segregate-refs.js)) decoupled the *editor* window for writers, **RefDiff** solves the diff-decoupling problem for *reviewers* on diff pages.

### Canonical Identifiers
* **Full Tool Name:** `RefDiff`
* **Conceptual Subtitle:** `Ref-Differentiator`
* **User Script / Gadget:** `refdiff.js` (for MediaWiki `Special:Diff`)
* **Archived Early Prototype:** Python proof-of-concept in [`archive/python-prototype/`](archive/python-prototype/)

## 2. Problem Statement: The "Template Camouflage" Crisis

On Wikipedia and Git documentation projects, **90% of quality control, vandalism patrolling, and fact-checking happens in the diff view (`Special:Diff`)**, not the edit window.

### The Current Flaw (Inline Entanglement in `wikidiff2`):
When a sentence contains a 500-character citation template (`{{Cite book |author=... |url=... |archive-url=... |access-date=...}}`), changing a single word in the sentence forces the diff engine to display the entire monolithic paragraph as modified:

```
Line 42:
[- The atmosphere consists mostly of carbon dioxide<ref>{{Cite book |author=Schmidt, Rainer |title=Planetary Atmospheres |year=2020 |pages=112–115 |isbn=978-3-12-345678-9 |publisher=Springer}}</ref>, creating an extreme greenhouse effect. -]
{+ The atmosphere consists mostly of carbon dioxide<ref>{{Cite book |author=Schmidt, Rainer |title=Planetary Atmospheres |year=2020 |pages=112–115 |isbn=978-3-12-345678-9 |publisher=Springer}}</ref>, creating a runaway greenhouse effect. +}
```

### Consequences:
1. **Vandalism & Hallucinations Hide in Template Clutter:** Subtle distortions (e.g. changing dates, numbers, or names) are masked by hundreds of characters of unchanged template parameters. Reviewers suffering from cognitive fatigue easily miss them.
2. **Ghost Diffs on Metadata Fixes:** Updating a broken URL or archive link marks the entire sentence as modified, corrupting `git blame` and misleading reviewers into thinking factual claims were altered.
3. **AI Slop Auditing Paralysis:** Reviewers evaluating whether text was generated by an LLM cannot inspect the source inventory without mentally disentangling template syntax from sentences.

## 3. High-Level Architecture: The Decoupled Diff View

`RefDiff` takes two revisions of wikitext (Old vs. New) and projects them into two specialized, synchronized views:

```
                      RAW REVISION A vs. REVISION B
                                    │
                                    ▼
                             [RefDiff Engine]
                                    │
          ┌─────────────────────────┴─────────────────────────┐
          ▼                                                   ▼
┌───────────────────────────────────┐       ┌───────────────────────────────────┐
│          PANE 1: PROSE DIFF       │       │    PANE 2: CITATION AUDIT DELTA   │
├───────────────────────────────────┤       ├───────────────────────────────────┤
│ The atmosphere consists mostly    │       │ 🟢 [Added] None                   │
│ of carbon dioxide ⟨1⟩, creating   │       │ 🔴 [Removed] None                 │
│ an [- extreme -] {+ runaway +}    │       │ 🟡 [Modified] 1 citation updated: │
│ greenhouse effect.                │       │    • ⟨~Schmidt 2020~⟩:            │
│                                   │       │      pages: [- 112 -] {+ 115 +}   │
└───────────────────────────────────┘       └───────────────────────────────────┘
```

1. **Pane 1 (Prose Diff):** Strips all citation markup into lightweight anchor badges (`⟨1⟩`, `⟨2⟩`). Shows **strictly human-readable text modifications**.
2. **Pane 2 (Citation Audit Delta):** Shows an isolated, parameter-level delta of all sources added, modified, or removed across the edit, prefixed with their corresponding badges.

## 4. Gadget Design & Implementation (`refdiff.js`)

`RefDiff` is built as an in-place client-side diff-decoupling gadget for MediaWiki `Special:Diff`. It runs directly in the browser via `common.js`, `global.js`, or user script extensions on English Wikipedia, Meta-Wiki, and all Wikimedia projects.

### 4.1 Placement & UI Integration
* Integrates directly into Wikipedia's native OOUI diff mode switcher (`.ve-init-mw-diffPage-diffMode .oo-ui-buttonSelectWidget`) alongside Wikitext and Visual Diff: `[ 👁 Visual ] [ [[]] Wikitext ] [ ⧉ RefDiff ] [ ] Inline modified refs`.
* Strictly adheres to native Wikipedia design with no extraneous banners or non-native status bars.
* Preserves native inline diff toggle (`Inline ( )`) and full Vector 2022 light/dark theme responsiveness (`clientpref`).

### 4.2 Mechanism & Core Capabilities
1. **Zero-Loss Native Diff Table:** Operates directly on Wikipedia's native 2-column diff table (`table.diff`), preserving 100% of revision metadata headers, line numbers (`Line 101:`), and context rows.
2. **In-Place DOM Memento (No Closure Detachment):** Avoids destructive `.innerHTML` replacement by updating table cells in-place and capturing a lightweight DOM snapshot. This ensures MediaWiki's `inlineFormatToggle.js` closures remain bound to live DOM nodes across mode transitions.
3. **3-Way Seamless Mode Switching:** Full bidirectional switching between `Visual`, `Wikitext`, and `RefDiff`. When switching to `Visual`, diff rows are cleanly hidden via `oo-ui-element-hidden` and synchronized with VisualEditor via `wikipage.diff.wikitextBodyUpdate` to prevent row leakage.
4. **"Inline modified refs" Mode Toggle:** Provides an intuitive in-toolbar toggle checkbox (`[ ] Inline modified refs`) allowing reviewers to choose between full decoupling (all citation changes placed in separate rows below, default unchecked) and inline modified references (modified references kept directly in prose with prepended `⟨~label~⟩` badges, added/deleted citations always separated).
5. **3-Pass Reference Pairing Engine:** Correlates deleted and added references using (1) explicit `name="..."` matching, (2) content-addressed string equality, and (3) positional order fallback. Anonymous citations count sequentially (`⟨ref1⟩`, `⟨ref2⟩`, `⟨ref3⟩`) in natural document reading order.
6. **Context Line Auto-Conversion:** If 100% of differences on a line are citations, the prose row automatically converts to neutral context appearance (`diff-context`), eliminating false text diff alerts.
7. **Prefixed Citation Diff Rows:** Injects matching citation diff rows (`<tr class="refdiff-cit-row">`) directly underneath each prose line, prefixed with their corresponding amber (`⟨~ref3~⟩`), green (`⟨+ref4+⟩`), or red (`⟨-ref5-⟩`) badge.
8. **Tag-Boundary Normalization & Cascading Protection:** Normalizes character-level boundary splits from `wikidiff2` (`&lt;/ref<del>&gt;` / `/<del>&gt;`) before regex matching, and uses lookahead-constrained tokenization to prevent unclosed tags from swallowing subsequent citations in high-density tables.
9. **Interactive Reference Badges & Native Reference Previews (`Extension:Popups`):** Badges are generated as semantic `<sup class="reference refdiff-ref"><a href="...">⟨label⟩</a></sup>`. Hovering over a badge displays Wikipedia's standard **Reference Preview hovercard** from Read mode. Automatically matches footnotes via template metadata (author, title), plain text, and positional numbering, while omitting native `title` tooltips to prevent visual clutter. Clicking an in-table link smoothly scrolls and flashes the corresponding citation diff row (`#refdiff-cit-...`).
10. **Shortened Footnote & Template Citation Decoupling (`{{sfn}}`, `{{r}}`, `{{efn}}`):** In addition to `<ref>` tags, natively detects Wikipedia footnote templates (`{{sfn|Author|Year|p=...}}`, `{{sfnp}}`, `{{sfnm}}`, `{{efn}}`, `{{r}}`, `{{harvnb}}`). Synthesizes clean author-year badges (e.g. `⟨Reichert & Wolfram 2010⟩`), separates page arguments into the decoupled citation row, and resolves `cite_note-FOOTNOTE*` anchor targets for instant native popup previews on hover.

### 4.3 Upstream MediaWiki Integration Vision (Parsoid / `wikidiff2`)
* In the future, MediaWiki's native PHP diff engine (`wikidiff2`) or Parsoid can adopt this pipeline natively as an official diff tab on `Special:Diff`:  
  `[ Standard Diff | Prose Only | Citation Audit ]`.
* For detailed analysis on client-side regex parsing vs. native preloaded MediaWiki libraries, see [**ARCHITECTURE.md**](ARCHITECTURE.md#91-evaluating-regex-parsing-vs-preloaded-mediawiki--meta-wiki-libraries) and [**LOG.md**](LOG.md#task-evaluate-regex-based-citation-parsing-vs-preloaded-mediawiki--meta-wiki-libraries).

### 4.4 Ecosystem Interoperability & Supplementing Tools
RefDiff is engineered for seamless coexistence with other widely used Wikipedia user scripts:
* ⚡ [**diffedit**](https://meta.wikimedia.org/wiki/User:Jon_Harald_S%C3%B8by/diffedit) ([`m:User:Jon Harald Søby/diffedit.js`](https://meta.wikimedia.org/wiki/User:Jon_Harald_S%C3%B8by/diffedit.js)): Injects an inline "Edit" link next to section headers on `Special:Diff` allowing editors to edit sections directly without leaving the diff view.
  * **Line-Enumeration Protection:** RefDiff assigns isolated CSS classes (`refdiff-cit-addedline`, `refdiff-cit-context`) to decoupled citation rows instead of native `diff-addedline` / `diff-context`, guaranteeing that `diffedit`'s line scanner (`enumerateLines()`) completely skips injected citation rows and maintains 100% accurate wikitext line numbering.
  * **Automatic Raw Wikitext Restoration:** When an editor clicks `[ Edit ]` or when `table.diff` gains `.diff-editmode`, RefDiff automatically restores native wikitext mode so the user edits raw wikitext instead of mathematical badges.
* ✍️ [**References Segregator**](https://en.wikipedia.org/wiki/User:PleaseStand/References_segregator) ([`User:PleaseStand/segregate-refs.js`](https://en.wikipedia.org/wiki/User:PleaseStand/segregate-refs.js)): Splits the wikitext editing textarea into clean prose above and reference definitions below during `Special:Edit`, serving as the editing companion to RefDiff's reviewing diff view.
* 🔍 [**HarvErrors**](https://en.wikipedia.org/wiki/User:Trappist_the_monk/HarvErrors) ([`User:Trappist the monk/HarvErrors.js`](https://en.wikipedia.org/wiki/User:Trappist_the_monk/HarvErrors.js)): Footnote integrity checker that flags broken or orphaned Harvard / shortened citations (`{{sfn}}`) in red. RefDiff's anchor resolver (`findCiteNoteAnchor`) targets the same anchor targets (`cite_note-FOOTNOTE*`).

## 5. Algorithmic Pipeline & Technical Design

```
Raw Wikitext (Old) ──► [Extract & Sentinelize] ──► (Clean Prose A, Raw Refs A)
                                                         │
                                                         ├──► [Word-Level Diff] ──► Prose Diff
                                                         │
Raw Wikitext (New) ──► [Extract & Sentinelize] ──► (Clean Prose B, Raw Refs B)
                                                         │
                                                         └──► [Raw Content Diff] ──► Citation Diff
```

### Step 5.1: Tokenization & Separation
The parser scans wikitext and segregates content into two discrete data structures without decoding or altering inner templates:
1. **Prose Stream:** Replaces all `<ref>...</ref>` and `<ref name="..." />` tags with opaque sentinel tokens: `⟦ref:schmidt2020⟧`.
2. **Citation Registry:** Stores the raw wikitext content of each `<ref>` span indexed by its identifier (`name` or position):
   ```json
   {
     "schmidt2020": {
       "raw": "{{Cite book |author=Schmidt |pages=112}}"
     }
   }
   ```

### Step 5.2: Prose Diff Calculation
* The prose stream is diffed using standard word-level sequence matching algorithms.
* Sentinel tokens are rendered as lightweight reference badges, named directly after the reference (e.g. `⟨schmidt2020⟩`) or indexed sequentially for anonymous references (`⟨ref1⟩`).
* **Badge Status Indicators (Angle Bracket Notation):**
  * Mathematical angle brackets `⟨...⟩` prevent visual collisions with Wikipedia's link syntax (`[external link]` and `[[wikilink]]`).
  * **Unchanged Citation:** `⟨schmidt2020⟩` (subtle secondary text via `var(--color-subtle, #72777d)` / `#8c9196`, normal font weight; zero blue highlight so unchanged citations blend cleanly with prose without mimicking hyperlinks).
  * **Modified Citation:** `⟨~schmidt2020~⟩` (bold amber/gold `#9a6700` / `#ffd043` with diff tilde notation, signaling modified underlying metadata).
  * **Added Citation:** `{+ ⟨esa2022⟩ +}` (green inline diff badge).
  * **Removed Citation:** `[- ⟨oldref⟩ -]` (red strikethrough inline diff badge).
* Even when only citation metadata changes, the prose sentence is displayed annotating the affected reference badge (`⟨~name~⟩`) so reviewers immediately understand the claim context.

### Step 5.3: Raw Citation Diff Calculation (No Template Decoding)
The tool compares `RawRefsA` against `RawRefsB`:
* **Added Citations:** Present in B, absent in A. Renders as `🟢 ADDED ⟨name⟩:` with `{+ ⟨name⟩ +} {+ <ref ...>...</ref> +}`.
* **Removed Citations:** Present in A, absent in B. Renders as `🔴 REMOVED ⟨name⟩:` with `[- ⟨name⟩ -] [- <ref ...>...</ref> -]`.
* **Modified Citations:** Present in both, but inner content or attributes changed.
  * In the browser gadget, citation diff rows (`<tr class="refdiff-cit-row">`) are inserted directly underneath the modified prose line and prefixed with the matching badge:
    ```
    ⟨~schmidt2020~⟩ <ref name="schmidt2020">{{Cite book |author=Schmidt, Rainer |pages=45–[- 48 -] {+ 52 +} |isbn=...}}</ref>
    ```
  * When **Inline modified refs** is enabled in the toolbar, modified citations remain in-place in the prose with a prepended badge (`⟨~schmidt2020~⟩<ref>...`), while added and deleted citations continue to decouple into dedicated citation rows below.
  * No template decoding, parameter extraction, or custom styling is performed—the exact raw wikitext diff is displayed with standard diff highlights (`[- old -]` / `{+ new +}`).

## 7. Synergy with `<references hidden>`

`RefDiff` and the native `<references hidden>` proposal form a powerful, bidirectional ecosystem:

1. **When an article adopts `<references hidden>`:**
   * The wikitext is already separated in database storage.
   * `RefDiff` renders instantly with 0 parsing overhead, simply highlighting the prose hunk and the `<references hidden>` hunk as distinct logical cards.
2. **When an article still uses legacy inline citations:**
   * `RefDiff` acts as a **virtual decoupling lens**: it parses the tangled inline wikitext in real-time on `Special:Diff`, presenting the reviewer with the same immaculate decoupled diff without requiring the article to have been converted.

## 9. Quick Start & Installation

### Option A: Global Installation (All Wikimedia Wikis at Once)
Add the following line to your **[Meta-Wiki global.js](https://meta.wikimedia.org/wiki/Special:MyPage/global.js)** to enable RefDiff across all language Wikipedias, Wikidata, and Wikimedia projects automatically:

```javascript
// [[File:refdiff.js]] - Decoupled citation diffs across all wikis (RefDiff)
mw.loader.load('https://meta.wikimedia.org/w/index.php?title=User:Powercycler/refdiff.js&action=raw&ctype=text/javascript');
```

### Option B: Local Wiki Installation (`Special:MyPage/common.js`)
To install RefDiff only on a specific wiki (e.g. English Wikipedia), add the following line to your local `Special:MyPage/common.js`:

```javascript
// [[File:refdiff.js]] - Decoupled citation diffs for Special:Diff
mw.loader.load('https://cdn.jsdelivr.net/gh/m-k/einzelnachweise@main/refdiff.js');
```

### Option C: Browser Extension (Tampermonkey / Violentmonkey)
Install `refdiff.js` directly as a user script in Tampermonkey, Violentmonkey, or Greasemonkey using the raw script URL:
`https://cdn.jsdelivr.net/gh/m-k/einzelnachweise@main/refdiff.js`

### Option D: Archived Python CLI Prototype
See [`archive/python-prototype/README.md`](archive/python-prototype/README.md) for running the archived Python 3 prototype:

```bash
# Compare local wikitext revisions
python3 archive/python-prototype/refdiff.py old.wiki new.wiki

# Compact diffstat summary
python3 archive/python-prototype/refdiff.py --stat old.wiki new.wiki
```
